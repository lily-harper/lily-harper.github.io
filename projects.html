Soul Meets Body meets NLP

Natural language processing on lyrics

Methods

NLP Text preprocessing Clustering

Tools

Python nltk pandas
Repository Read reflection

Question

Are there patterns or trends that can be found in lyrics written by Benjamin Gibbard?

Approach

Clean text, tokenize, and use lexical sentiment tools. Compare unsupervised groupings and interpret clusters carefully instead of treating them as definitive labels.

Summary

I clean the data, tokenize on whitespace for word counts, then implement TF-IDF vectorization to represent the lyrics per song as a matrix, wherein the songs become columns and individual words are rows.
VADER was used to evaluate sentiment per song and for each album. I reduce the dimensionality with TruncatedSVD (2 components for simple plotting and 10 for clustering). Finally, I cluster using KMeans and evaluate the clusters.
To choose a reasonable number of components, I use elbow plots and explained variance to assess the tradeoff between dimensionality reduction and retained information. To choose the number of clusters, I compare clustering metrics such as the Silhouette Score and Davies–Bouldin Index.

Pipeline

The pipeline pulls raw Genius lyric data, cleans and normalizes the songs, then builds TF-IDF features with VADER sentiment scores and TruncatedSVD components. It uses those features to create clustering outputs, public lyrics-free CSVs, model artifacts, and report figures for interpretation.
