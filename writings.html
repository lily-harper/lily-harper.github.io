What Makes an Analysis Reproducible?

Methods note · Draft

Reproducibility is not only about whether code runs. It also depends on whether the assumptions, data cleaning choices, model comparisons, and limitations are visible enough for someone else to follow the path from question to conclusion.

This post can expand into a short reflection on notebooks, project structure, documentation, and the difference between polished results and transparent work.

Model Accuracy Is Not the Whole Story

Modeling reflection · Draft

Accuracy can be useful, but it rarely explains whether a model is appropriate. A careful analysis should ask what errors matter, who is affected by those errors, and whether the model is actually answering the original question.

This post can connect classification metrics, baseline models, interpretability, and practical judgment in entry-level data science projects.
